## Known limits

- The here.now Free plan allows **one** custom domain. A second domain
  needs a paid plan; DNS alone cannot HTTP-redirect one domain to another.
- A static site has no runtime. Anything that needed a server — auth,
  form POSTs, scheduled jobs, API routes — is gone, not moved.
